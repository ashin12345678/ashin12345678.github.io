shorts-desktop-readonly

運営者本人が、自分のYouTubeチャンネルをWindows端末で管理するための個人用アプリです。このサイトはアプリの説明文書です。一般向けの登録、販売、ログイン、動画操作は提供していません。

現在はAPI方式への移行を検証中です。Googleの審査完了、本番運用の開始、継続的な投稿成功を示すサイトではありません。

YouTube API Servicesの利用

本アプリはYouTube API Services（YouTube Data API v3）を利用します。Google OAuthによる認可で対象チャンネルを照合し、動画の公開設定・処理状態などを確認します。登録済みアプリ名は上記の名称です。

非公開アップロード、公開日時の予約、公開結果の照合のコードは準備中の運用に含まれますが、APIによる実アップロード・予約の検証はまだ完了しておらず、自動投稿は有効にしていません。

権限と操作

使用するOAuthスコープは youtube.force-ssl です。このGoogle権限には動画等の閲覧・編集・削除が含まれますが、本アプリにYouTube動画の削除機能はありません。権限への同意と、動画のアップロード・公開予約の実行承認は分けて扱います。

アプリを利用する前に、利用規約とプライバシーポリシーを読み、同意する必要があります。説明サイトの閲覧だけで同意やOAuth認可を記録する機能はありません。

お問い合わせ

運営者本人だけが利用する開発段階のため、本人からの問い合わせ・保存データ削除の依頼は通常の非公開の運用連絡経路で受け付けます。Google同意画面に表示されるサポート連絡先でも確認できます。認証情報や個人データを公開Issueへ書き込まないでください。
